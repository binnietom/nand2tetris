# Installation

## Stable release

To install nand2tetris, run this command in your terminal:

```sh
uv add nand2tetris
```

Or if you prefer to use `pip`:

```sh
pip install nand2tetris
```

## From source

The source files for nand2tetris can be downloaded from the [Github repo](https://github.com/Tom Binnie/nand2tetris).

You can either clone the public repository:

```sh
git clone https://github.com/Tom Binnie/nand2tetris
```

Or download the [tarball](https://github.com/Tom Binnie/nand2tetris/tarball/main):

```sh
curl -OJL https://github.com/Tom Binnie/nand2tetris/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd nand2tetris
uv sync
```
